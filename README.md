# foundation-website
A website for a foundation, sharing its mission, programs, and ways to get involved.

## Pages
- **Home** (`index.html`): introduction and main message
- **Our Program** (`our program.html`): the foundation's programs and activities
- **Gallery** (`gallery.html`): photos from events and work
- **Volunteer** (`volunteer.html`): how to join and help
- **Contact** (`contact.html`): contact details and enquiries

## Built With
- HTML
- CSS (`style.css`)
- JavaScript (`javascript.js`)

## Project Structure
- `images/`: photos and graphics used on the site
- `style.css`: styling for all pages
- `javascript.js`: interactive features

## How to Run
1. Clone the repository:
   `git clone https://github.com/Peisntech/FOUNDATIONWEBSITE.git`
2. Open `index.html` in your browser.
